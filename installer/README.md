# Vocalis 1.0.0 Windows installer

Build with Inno Setup 6.3 or newer. No compiler or runtime is downloaded by the
helper. Install Inno Setup manually from https://jrsoftware.org/isdl.php, then:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File installer/BuildInstaller.ps1
# Or specify an existing compiler:
# ... -IsccPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

Stable AppId: **745846CB-3E2F-4EB3-9D76-6B6B3469742A**. Keep this identifier for
future Vocalis installer upgrades. It is separate from plugin/VST3 identifiers.
Output: `dist/Vocalis-1.0.0-Setup.exe`.

The plugin is copied from the current Release build, including the embedded logo.
No CMake/plugin build or modification occurs. The existing distribution ZIP
predates the logo update; it is deliberately not rebuilt by this packaging task.
The helper updates hashes for the actual existing ZIP and newly compiled EXE,
retaining other checksum entries.

## Paths and scope review

- `{commoncf64}\VST3\Vocalis.vst3`: complete bundle contents, exactly one outer
  Vocalis.vst3 directory. The recursive source wildcard is INSIDE the bundle.
- `{commonpf64}\Vocalis`: README, notices, dependency licences, release checklist,
  audit and uninstaller. LICENSE.txt is required, displayed for acceptance, and installed.
- Administrative elevation, fixed documentation location, 64-bit installation
  mode, Windows 10 minimum. x64compatible follows Inno's architecture convention;
  ARM Windows emulation is not separately validated for this VST3/host combination.
- Upgrade/uninstall recursive removal targets only the exact Vocalis.vst3 bundle,
  never its parent. Treat bundle contents as application-owned, not user storage.
- Documentation uses tracked-file uninstall and empty-directory removal. Extra
  user-added files are retained, so a nonempty documentation directory survives.
- Close DAWs first; old-bundle cleanup is not transactional rollback protection.
- No custom registry entries, COM registration, FL Studio changes or host launch.
  Inno's normal uninstall registration is intentional.
- Optional, unchecked README opening uses Notepad. No internet action at setup.
- VC++ runtime is DOCUMENTED on welcome/info pages and README, not detected or
  bundled. Install Microsoft's supported x64 runtime separately when required.
- Signing is disabled. The .iss marks where a trusted SignTool can be added.
- TODO: approved BMP/ICO branding assets; the original PNG is untouched and
  default Inno wizard graphics do not require conversion to compile.
